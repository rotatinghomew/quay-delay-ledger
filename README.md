# 港区转运减时的反事实复盘与合同额度

码头、堆场和短驳岗位按箱程复核合同可计时长及减时补救。

## 资料和运行环境

`data/` 提供本地合成业务资料。各业务文件为 UTF-8 JSON 数组，键、单位和关联见 [资料字典](data/README.md)。`format.json` 记录列集合和基础引用约束。

使用 Python 3.11。在普通 Python 环境可用 `python3 -m pip install -r requirements.txt` 安装锁定的分析依赖。检查提供的资料可运行：

```sh
python3 -m unittest discover -s tests -v
```

资料检查覆盖文件可读性、字段与明确的单列引用。业务原始记录允许保留冲突、未决关系及尚未到达的观察。

## 联合复盘工具

`drayage_review/` 在同一套混合整数调度模型上合并船侧、堆场、短驳三份记录，输出
联合可行箱程、边际反事实归因、合同计费与补救评估，并支持按账期滚动对账。方法、命令
与确认单规则见 [工具说明](docs/工具说明.md)。

```sh
python3 -I drayage_review_cli.py run --as-of 2026-06-07 --out out/run
python3 run_tests.py          # 或 python3 -m unittest discover -s tests（37 项测试）
```

设计要点：

* 交接时刻是区间变量，不挑对某方最有利的单点；合同计时给联合可行包络与争议差额；
* 归因用边际反事实区分"明确可归因"与"仅联合范围"，禁止各方本地节省相加；
* 无可行箱程逐箱隔离，受影响计价项目拦下，其他箱照常复盘；
* 组合补救按真实箱程重解，份额分不出去就留空；确认单防重复认领、待调整额度冻结。
