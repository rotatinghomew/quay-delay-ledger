# 资料字典

所有窗口单位为中国时区当地日内分钟，各设施窗口的名额同一时刻只能供一个箱程使用。合同可计等待为所列节点之间扣除免费时间后非负的分钟数，费率用人民币。没有确定操作完成时刻的记录不视为确定。设施限制允许部分并行，装卸泊位必须覆盖船侧交接，短驳资源覆盖接手之后的装运，箱程在船侧和堆场均交接完成后才可装运。补救申请表示相同运行条件下可将对应资源窗口的起点最多提前的幅度。

## `cargo.json`

一个预约可有多箱，箱程按箱与船次标识。

| 字段 | 含义 |
| --- | --- |
| `box` | 箱号 |
| `vessel` | 船次 |
| `appointment` | 共用预约号 |
| `day` | 箱程日 |
| `kind` | 箱型 |
| `cutoff` | 实际船侧截止分钟 |
| `district` | 交付区域 |

## `events.json`

时段内不确定的交接时间保留上下界。

| 字段 | 含义 |
| --- | --- |
| `event` | 原事件 |
| `box` | 箱号 |
| `kind` | 交接方式 |
| `day` | 事件日 |
| `lo` | 最早可证分钟 |
| `hi` | 最晚可证分钟 |
| `available` | 记录可见日 |
| `revision` | 事件修订 |
| `vehicle` | 车辆号，可空 |

## `barriers.json`

箱侧限制与可解除的单项停留。

| 字段 | 含义 |
| --- | --- |
| `box` | 箱号 |
| `kind` | 限制种类 |
| `facility` | 受用设施 |
| `day` | 有效日 |
| `open` | 可用窗口始点分钟 |
| `close` | 可用窗口终点分钟 |
| `service` | 所需专占设施时长分钟 |

## `capacity.json`

运行日实际共享的数据。

| 字段 | 含义 |
| --- | --- |
| `vessel` | 关联船次 |
| `facility` | 设施 |
| `scope` | 能力类别 |
| `day` | 值班日 |
| `open` | 值班开始分钟 |
| `close` | 值班结束分钟 |
| `units` | 同一时刻可用单位 |

## `terms.json`

合同减时试算和分配的有效条件。

| 字段 | 含义 |
| --- | --- |
| `contract` | 合同号 |
| `party` | 签约方 |
| `facility` | 适用的活动限制 |
| `rate` | 可计等待每分钟元 |
| `reserved` | 补助预算元 |
| `count_from` | 起计节点 |
| `count_to` | 截止节点 |
| `free` | 免费等待分钟 |

## `remedies.json`

拟临时改变某个限制，其他观察条件按运行日。

| 字段 | 含义 |
| --- | --- |
| `remedy` | 补救编号 |
| `facility` | 被改变的限制 |
| `box` | 候选箱 |
| `gain` | 可提前的时间分钟 |
| `cost` | 请求额元 |

## `acceptances.json`

业已签认的额度及未决调整。

| 字段 | 含义 |
| --- | --- |
| `acceptance` | 书面编号 |
| `contract` | 合同号 |
| `box` | 收益箱程 |
| `remedy` | 补救方案 |
| `amount` | 额度元 |
| `state` | 当前书面状态 |
| `day` | 确认日 |
